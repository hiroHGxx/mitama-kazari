## 1. なぜ仕上げるか（現状の所感・2026-09-02 実機寸法で確認）

いまの画面は「題 → 額 → 選ぶ▾ → 01〜10 → 写真に保存 → 長文」の**道具の型**。動くが、推しを選ぶ喜びが無い。

- 「選ぶ▾」は設定画面の部品。29柱の顔はモーダルの中に隠れ、最初の画面に顔がいない
- 深さは「01〜10」の番号だけ。「10段は同じ絵の枠違いではなく、闇から顕れる10枚」（企画書§1③）が数字の裏に隠れている
- 最初の画面に説明文が多い（深さの注・壁紙の手順の長文・脚注）
- 起動時は「顕れています…」の待ちがそのまま見える

**実測: 速い回線では 0.38秒で絵が出る**（domcontentloaded 280ms／絵 378ms／保存可 393ms）。
「帳が読み込みを隠す」効果は薄い。だから帳は**長い幕ではなく短い「顕れ」**にする（§2.1）。

## 2. 仕様

### 2.1 開幕＝「顕れ」（SHITSURAE §1 の時間割をそのまま使う）

幕（黒緞子・左右に開く）は**採らない**。道具に幕は重く、声も無い。
代わりに、**額の中で札絵が闇から顕れる**——この道具の芯（顕れの深さ）と同じ動きを開幕に使う。

| 時刻（ページを開いた時刻が起点） | 何が起きるか |
|---|---|
| 0ms | 地（宵闇藍の二色）と蝕環だけが額に描かれている。周りの部品（題・帯・保存・下の節）は **opacity 0 / pointer-events none**（レイアウトは占めたまま＝あとで跳ねない） |
| 札絵が届いた時 | 額の中で絵が **0→1 に 600ms** で顕れる（canvas を rAF で `globalAlpha` を上げながら描き直す。地と蝕環は最初から出ている） |
| 1200ms | 周りの部品が **0→100% を 700ms で一段**で立ち上がる（踊り場を作らない） |
| 1260ms | 押せる（pointer-events 復帰） |
| 1900ms | 完全不透明 |

- **画面のどこをタップしても飛ばせる**（部品が即座に立ち上がる。絵の顕れは途中でも 1 へ）
- 絵が 1200ms までに届かなくても、部品は 1200ms に立ち上がる（待ちの起点はページを開いた時刻。画像の onload を起点にしない）
- 読み込みの保険: 5秒たっても絵が来なければ「顕れています…」を今までどおり出す
- 2回目以降の来訪も同じ時間割（視覚の演出だから）。タップで飛ばせるので害は無い
- 声・音は入れない
- **題の顕れ（2026-09-02 オーナー裁定A・「アプリとしてのタイトル画面は不要か」への答え）**: タイトル画面は作らない（0手を守る）。
  代わりに開幕の 0〜1200ms、額の**時計の帯**（上17%）に題字「夜じたて」を大きく（額の幅の0.19倍・24〜32px）浮かべ、
  部品が立つ 1200ms に小見出し h1 の位置へ縮んで収まる（動き700ms・不透明度は350msで先に消える）。DOM なので保存画像には入らない。
  見送り: B「初回だけタイトル画面」（初回に1タップ）・C「毎回タイトル画面」（兄弟作と揃うが0手の裁定と食い違う）

### 2.2 顔を最初の画面に出す（帯）

「選ぶ▾」の代わりに、額の下に **29柱の顔の帯**（横スクロール・`scroll-snap`）を置く。

- 並びは ROSTER の里の順（甲賀→伊賀→雑賀→風魔→根の国）。里の境に 6px 余分の隙間
- 1柱＝`<button aria-pressed>`（`<img>` に click を付けない）。中身は顔アイコン 44px ＋ 名前 12px（床）。押し所は両辺44px以上
- **選んだ柱の印は金泥の面**（`rgba(217,169,76,.16)`＋縁 `rgba(217,169,76,.45)`）。輪では出さない（円の光り物は蝕環ひとつ）
- タップで額の中が入れ替わる。**入れ替わりも「顕れ」**（新しい絵を 350ms で 0→1。地は消えない）。モーダルに潜らない
- 開いた時と選んだ時、帯はその柱を中央に寄せる（`scrollIntoView({inline:'center'})`）
- 顔アイコンは `loading="lazy"`（合計2.6MB。見えているぶんだけ取る）

**名札**（額と帯のあいだ・1行）: `咲耶　さくや／甲賀・火`。`id="chooser"` の `<button>` のまま（min-height 44px）。
押すと**既存の「御霊を選ぶ札」（`#picker`）が開く**——名前で探して飛ぶ用。帯＝隣を流し見る、札＝名前で飛ぶ、と役を分ける。
札の開き方・閉じ方（✕・外側タップ・Esc）は変えない（`scripts/check-layout.js` が測っている）。

### 2.3 深さを「顕れ」として見せる（段）

「01〜10」の番号の箱をやめ、**10段の階梯**にする。

- 10個の `<button aria-pressed>` は残す（`#depth button`・押し所 24px 以上・`scripts/check-layout.js` `check-frame.js` がこの選択子で押す）
- 見た目: **選んだ段まで金泥が満ちる**（1段目 `rgba(217,169,76,.18)` → 選んだ段 `#D9A94C`。段ごとに不透明度を上げる。選んだ段だけ `#F0CE7E`）。上の段は地のまま
- 数字は**選んだ段にだけ**出す（12px以上）。他は出さない（`aria-label="深さ n"` は全段に残す）
- 見出し1行: `顕れの深さ　05／10`（12px・補助文字 `#9D93B5`）。今の注記（「浅いほど暗く静かに〜」）は詳細の中へ移す（§2.5）
- **なぞって選べる**（pointerdown → pointermove で指の下の段を選ぶ・pointerup で確定）。なぞっている間は印と数字だけ動かし、**絵の読み込みは指を離した時**（または150ms止まった時）に1回
- 焼き上がったら、**同じ御霊の残り9段を後ろで先読み**する（`new Image()`・crossOrigin anonymous・順は選んだ段の隣から外へ）。2回目以降のなぞりは即座に顕れる。御霊を替えたら先読みは新しい御霊へ（古いものは捨てるだけ・止めなくてよい）

### 2.4 保存の後に案内を出す

「写真に保存」→ 共有シートが**完了**したら（`navigator.share` が resolve／download 経路が通った）、
**「壁紙にするとき、ひとつだけ」の札**を出す（`#picker` と同じ「開いて閉じる札」の型・SHITSURAE §7）。

- 中身は今の `.howto` の2段落そのまま（写真アプリ→共有→壁紙に設定／iOSは顔まで拡大する→指2本で縮める／正体は「被写体を切り取る」→ショートカット2手のリンク）
- 閉じ方: ✕・外側タップ・Esc
- 取り消された時（AbortError）は出さない（保存していない）
- 一度閉じたら、そのセッションでは次の保存でも出す（毎回。手順を忘れる人のため）

### 2.6 額の大きさ

## 3. 設え（守るもの）

- 色は `:root` の系だけ（`--night` `--night-2` `--panel` `--kindei` `--kindei-hi` `--ink` `--ink-dim` `--line`）。新しい hex を作らない
- 文字 12px 未満を作らない。押し所は両辺 24px 以上（帯の顔は 44px）
- 角丸は 4／5／10（作品の系）。帯の顔 4・釦 5・面 10
- 押し所を画面のいちばん下端に置かない（ホームバーに飲まれる）
- 透過は通過点。0.7秒で通り過ぎる。とどまる透過を作らない
- 額の幾何（`window.__yojitate` の値・`paintRing`）は変えない

## 5. 見送ったもの（理由つき）

- **幕（黒緞子が左右に開く帳）**: 兄弟作と揃うが、道具に毎回 1.65＋0.9 秒の幕は重い。声も無い。「顕れ」で芯を見せるほうが短くて筋が通る
- **深さのスライダー（`<input type=range>`）**: iOS の標準スライダーは10刻みを指で当てにくく、見た目も系の外。10段の階梯をなぞれるようにして同じ手触りを得る
- **10段のサムネ帯**: 1御霊あたり10枚（1〜3MB）を見せるために取ることになる。先読みは裏でやり、見せるのは額ひとつ
- **帯と札の一本化**: 帯だけだと名前で飛べない（29柱は3画面分）。札だけだと顔が最初の画面にいない。役を分けて両方残す
- **銘（御霊の名）の焼き込み／ロック・ホーム出し分け／他端末用の寸法選択**: §0 の裁定どおり声があったら

## 7. 第6便「額を画面に」（2026-09-02 オーナー裁定A）

### 7.0 きっかけ

第5便を実機で見たオーナーの感想: **開幕は問題なし。選んだ絵をもう少し大きくしたい。**
縦積みでは額を伸ばすと下の部品（名札・帯・階梯・保存）が画面外へ出る（48svh が頭打ち）。
案A（額を画面に＋引き出し＋≡）／B（横に寄せる・約2倍）／C（≡だけ・絵は大きくならない）を出し、**A に裁定**。
理由: この道具の芯は「その端末にぴったり合う」。額は端末と同じ比率なので、画面そのものにするのが芯に近い。

### 7.1 骨（1画面のアプリ・頁は流れない）

```
┌──────────────────┐
│ ≡        夜じたて │ ← ≡ は額の外の袖（左右の余白）に。題字は額の時計の帯に常設（18px・金泥）
│                  │
│      札 絵       │ ← 額。**常に全部見える**（引き出しに覆われない）
│                  │    引き出しの高さに合わせて contain で伸び縮み（transition 300ms）
│                  │
├─── ── ───────────┤ ← つまみ（44px・タップと上下スワイプで開閉）
│ エマ えま／甲賀・金 ▾│ ← 名札（44px・押すと従来の札＝名前で選ぶ）
│ [顔の帯]          │ ← 開いているときだけ
│ 顕れの深さ 09／10 │ ← 開いているときだけ
│ [階梯]           │
│ [   写真に保存   ] │ ← 常に。下端は env(safe-area-inset-bottom) ぶん浮かせる
└──────────────────┘
```

- `#app{position:fixed;inset:0;height:100dvh}`（`100vh` を先に書いて古い端末の保険）。`body{overflow:hidden}`。**頁はスクロールしない**
- 地は `--night`。引き出しは `--night-2`（二色一組はここで保つ）。**引き出しは不透明**（透過は通過点。とどまる透過を作らない）
- 額は上の領域（画面 − 引き出し）に `contain`（`max-height:100%`＋`aspect-ratio`）で置き、**上下左右とも中央**。
  幅 393×740（Safari のバー表示中）の見込み: **閉＝約267×580px／開＝約197×428px**（第5便は 164×355）
- ≡（44px・`aria-label="ほかの案内"`）は左上、額の袖（左右の余白）に。額が画面幅いっぱいになる端末では時計の帯の上に乗せる（帯は暗い地なので読める）
- 題字 `h1` は額の時計の帯（上17%）の中に常設。**開幕の題の顕れは「同じ場所で大→小」**に変わる（着地の移動が要らなくなる。着地のコードは簡素化してよい）
- 副題「札絵を、その端末の夜に合わせて額装します」は最初の画面から外し、≡ の札の冒頭に置く
- 破線のガイド（時計の帯・釦の帯）は据え置き

### 7.2 引き出し（bottom sheet）

- 状態は **開／閉** の2つだけ。既定は**開**（0手で選べることを守る）。閉じると額が大きくなる
- 開閉: つまみのタップ／つまみ・名札の上での縦スワイプ（上＝開・下＝閉）。`aria-expanded` を付ける
- 中身の順（上から）: つまみ → 名札 → **[開のとき] 帯 → 見出し＋階梯** → 保存 → 二次創作の一行（12px・補助文字。KITAN.md「画面にも1行」）
- 閉のときの背丈 ≈ つまみ44＋名札44＋保存48＋一行18＋余白＋safe-area。**保存の下端は画面の最下端に置かない**
- 開閉の記憶はしない（毎回「開」で始まる）
- 帯・階梯・名札・保存の中身と作法は第5便のまま（id も変えない）

### 7.3 ≡ の札（メニュー）

`#picker` と同じ「開いて閉じる札」の型（✕・外側タップ・Esc）。中は縦スクロール（`.pick-body`）。順に:

1. 副題の一行
2. 「壁紙にする手順」（`#howtoText` の2段落そのまま）
3. 「毎朝ひとりでに替えるなら」（`#dailyBox` の中身・id・`hidden` の挙動・`#copyUrl` の JS を**一切変えない**。ここへ移すだけ）
4. 「この端末で通ったこと」（`#log`）
5. 脚注（破線の但し書き・二次創作の明記・原本を配っていない）

### 7.4 変えないもの

第5便 §0 のすべて（額の幾何・書き出し・ROSTER・副・保存の3経路・iOS 抑止・localStorage の try）。
保存後の札（`#tips`）・御霊を選ぶ札（`#picker`）・開幕の時間割（1200／1260／1900ms・タップで飛ばす）も据え置き。
階梯の `touch-action` は頁が流れなくなるので `none` に戻してよい（縦送りに返す理由が消える）。

### 7.5 受け入れ基準（`check-layout.js` を第6便の骨に合わせて書き直す。既存の判定は残す・緩めない）
